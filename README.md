# MRCG-Updated-Antibiogram-Draft
Here is the R project for "Optimizing Empiric Therapy Through Updated Antibiogram Surveillance (2020–2025): Emerging Resistance Trends and Stewardship Implications in The Gambia"

The project contains all code, figures and tables generated for the paper, coded by Gorrgi-Sam John. 

I made use of the 'tidyverse' package.
